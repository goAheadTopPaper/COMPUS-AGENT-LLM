# Plan 2. eStudent 公开科目搜索接入 Policy 分支

## 状态
已完成（分支 `feature/supervisor-scheduler`）

## 目标
新增 `subject_api.py`，把理大 eStudent 公开科目接口（`https://estudent.polyu.edu.hk/e-public/subject-search/listing?mode=subject` 背后的 API）转换成 `INTEGRATION.md:8` 要求的完整 Policy `search()` 字典，作为 Policy 分支可注入的数据源。

## 环境事实（实测）
- 页面是 React SPA，HTML 只有壳；浏览器直连报 `ERR_CONNECTION_CLOSED`，Python urllib 直连接口正常。
- 搜索接口：`POST /proxy/e-public/srs-api/student-portal/public/subjects/search`，body 字段 `subjCode` / `title` / `acadYearSem` / `term` / `orgUnitId` 等；匿名可访问。
- 详情接口：`GET /proxy/e-public/srs-api/student-portal/public/subjects/{id}`，带 `preRequisitesConstraintMap`、`coRequisitesConstraintMap`、`exclusionConstraintMap`、`subjectPlannedComponents`、`subjectTitles`、`organizationUnit` 完整名称。
- 实测 COMP5926（id 41275）：摘要里 `preRequisitesConstraintMap={}`，详情里为 `{"47596":[{"subjCode":"COMP5925","effAcadYear":"2023","effAcadSemester":"1",...}]}`。先修在详情接口，**不在摘要接口**。
- 实测 `{"subjCode":"COMP5926"}` → 1 条；`{"title":"Metaverse"}` → 6 条；`{"title":"Data"}` → 266 条（必须限制候选数并触发澄清）。

## 需求→步骤映射
| 需求（来源） | 步骤 | 出口校验 |
|---|---|---|
| Policy 交付完整 search 字典：`results/status/year_filters/limitations/requires_*_clarification`（INTEGRATION:8） | `search()` 固定返回这五个字段（无候选时也有） | 测试逐字段断言 |
| evidence 保留 `evidence_id`/`text`/`citation.title`、来源链接、学年、警告（INTEGRATION:8） | 每条 evidence 带齐字段，`citation.source_url` 指向 eStudent 页面 | 测试断言字段完整 |
| ID 与索引一致、同查询稳定（INTEGRATION:8） | `policy:estudent:<CODE>:<fact>[:<target>]` 确定性生成，不依赖检索排名 | 重复调用 ID 相同 |
| 未查到保留状态与空 results（INTEGRATION:8） | `status=no_results`、`results=[]` | 无结果用例 |
| 事实必须来自接口，不编造（Answerer/Verifier 契约 agents.py:28-44） | 约束只从详情 map 渲染；空 map 生成"未登记"证据而非虚构科目 | COMP5926 用例断言 `COMP5925` 出现在先修证据中 |
| 多候选需澄清（INTEGRATION:49） | 标题查询 >1 条且无精确代码时 `requires_subject_clarification=True` | 模糊标题用例 |
| 失败由 Supervisor 记录（INTEGRATION:9） | 搜索阶段网络异常直接抛出；详情失败降级为 limitation，不抛 | 异常透传 + 详情降级用例 |
| 可离线联调，不依赖校园网 | 注入 `fetcher(method,url,payload)`，默认 urllib | 假 fetcher 测试 + 与 supervisor.run 端到端 |

## 关键决策
- 只依赖标准库 `urllib`，不引入 requests，保持队友代码零依赖约定。
- 详情接口只对前 `max_candidates`（默认 5）个候选取，避免标题宽泛时打 266 次请求。
- evidence 文本用英文原子事实句，便于 Verifier 逐字引用；中文问题由 Answerer 负责翻译。
- 约束证据带 `effAcadYear` / `effAcadSemester`，防止跨学年误用；`limitations` 明确"公开目录只反映登记记录，非官方豁免证明"。
- 搜索阶段异常透传给 Supervisor（标记 failed）；详情阶段异常降级为 limitation（分支仍有部分证据可用），两者不混为一谈。

## 边界与失败模式
| 失败模式 | 处置 |
|---|---|
| 标题命中 266 条 | 截断到 max_candidates，`requires_subject_clarification=True`，limitation 说明截断 |
| 科目代码不存在 | `status=no_results`，空 results，不抛异常 |
| 详情 404/超时 | 跳过详情证据，加 limitation；摘要证据保留 |
| 详情约束 map 为空 | 生成"no registered ... in eStudent"证据，不虚构 |
| `subjectTitles` 无英文键 | 回退任意语言键，仍无则省略 title 证据 |
| 网络整体不可用 | 抛出 `OSError`/`HTTPError`，由 Supervisor `_branch_state` 捕获脱敏 |

## 二阶效应
只发起只读 GET/POST，不写文件、不改队友代码、不接触 token。对 eStudent 公开接口产生少量查询流量（每次最多 1+5 请求）。
