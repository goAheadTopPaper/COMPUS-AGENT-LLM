# Demo 录屏分镜（4 分钟）

目标：4 分钟内让人看懂三件事——**它会答复杂问题、答得能追溯、不会答时明确拒绝**。
不要讲架构图，讲屏幕上正在发生什么。

---

## 录前检查（3 分钟，别省）

1. 服务在跑：浏览器打开 http://localhost:8511，侧栏显示绿色「真实 pipeline · DeepSeek 生成 · Verifier 校验」
   - 没显示 → 终端执行 `POLICY_RAG_HOME="/Users/J3rk/Desktop/PolyU/Sem1/COMP5584_LLM4Agent/part1" python3 -m streamlit run app/streamlit_app.py`
2. 窗口尺寸调到 **1440×900**，浏览器缩放 **100%**（`⌘0`），`⌘⇧B` 隐藏书签栏
3. 开勿扰模式（`⌘⇧⌥` 长按控制中心），关掉微信、邮件通知
4. **先手动点一次第一个问题预热**（首次要加载索引，约 1.5 秒），然后**刷新页面**再开始录
5. 确认屏幕上没有终端、没有 `.env`、没有 MOCK 字样

## 分镜

| 时间 | 操作 | 屏幕上应出现 | 字幕 |
|---|---|---|---|
| 0:00–0:15 | 停在未提问的首页，不要动 | 标题、三个预设问题按钮、左侧「学生画像 / 演示设置 / 真实 pipeline」 | 多智能体校园信息助手。左侧是运行状态，右侧会实时显示每个 agent 的动作。 |
| 0:15–0:25 | 点**第 1 个**按钮 | 出现「agent 协作中…」，约 4–7 秒 | 问题涉及考试缺考处理，需要跨章节检索。 |
| 0:25–0:50 | 等结果出来，不要滚动 | 「已通过校验」绿色徽章 + **7 条要点**，每条结尾带 `[1] [2]` | 答案被拆成 7 条原子结论，每条都挂着证据编号。 |
| 0:50–1:20 | 展开**第一条证据卡** | 来源文件、页码、章节、权威等级、原文片段 | 每条结论都能追到原文的哪一页——不是模型记忆。 |
| 1:20–1:50 | 视线移到右侧 trace，鼠标沿事件往下走 | 5–6 行：Supervisor 派发 → policy 命中 N 条 → Answerer → Verifier | 右侧不是动画，是真实的调度记录：谁派发、谁检索到几条、谁判定通过。 |
| 1:50–2:10 | 鼠标停在最后一行 `证据门` | `pending_semantic_review（原始文件哈希与索引一致）` | 这一行在校验原始 PDF 的哈希，确认引文确实出自那份文件。 |
| 2:10–2:40 | 点**第 2 个**按钮 | 约 2 秒出结果，**单个要点**：GPA 低于 1.70 | 数字型问题。1.70 来自条文本身，Verifier 会核对这个数字与证据是否一致。 |
| 2:40–3:15 | 点**第 3 个**按钮 | 灰色「拒答」徽章；右侧 Verifier 红框「0 条证据」；底部 **1.2 s / token 0** | 2020/21 的规则不在语料里。系统没有调用模型，也没有猜——直接说明收录范围。 |
| 3:15–3:35 | 鼠标指回结果区顶部的四个指标 | 3.4 s / 4 次调用 / 7.8k token / 成本（**无需滚动**） | 一次完整问答的代价：三秒多、四次 agent 调用。 |
| 3:35–4:00 | 静止，不要动 | 停在拒答画面 | 会答、答得准、知道不答——这是我们做多智能体的理由。 |

## 三条必须录到的画面（缺一条就重录）

1. **7 条要点那次**（第 1 题）——证明它真在生成，不是拼接段落
2. **证据门那一行**（1:50 附近）——全项目最有技术含量的一处，字幕一定要配
3. **拒答页面的 token 0**（第 3 题）——证明拒答是流程拦截，不是模型自由发挥

## 常见失败点

| 现象 | 原因 | 处理 |
|---|---|---|
| 点击后一直转圈 | 索引没预热 / 服务挂了 | 先手动点一次，刷新再录 |
| 侧栏是「真实检索」不是「真实 pipeline」 | `.env` 或 `POLICY_RAG_HOME` 没生效 | 检查终端启动命令，重启服务 |
| 答案变成中文 | 模型偶尔语言判断错 | 重录这一条；连续两次就换问题 |
| 底部指标显示 `0.0 s` | 旧版本没刷新 | `⌘⇧R` 强制刷新 |
| 录到一半报错 | DeepSeek 超时 | 网络问题，重录该段 |

## 录完自检

- 总时长 3:30–4:30 之间
- 没有出现终端、聊天窗口、`.env` 内容
- 三个按钮都被点到，拒答那次在最后
- 字幕与画面对得上（时间轴 ±3 秒可接受）
