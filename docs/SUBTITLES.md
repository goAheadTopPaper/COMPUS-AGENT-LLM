# 字幕稿（配现有 75 秒录屏，无需录音）

原则：**字幕写“为什么”，不写“点了什么”**。观众看得见你点了按钮，看不见的是这五行为什么重要。

时间按现有素材估的（t=0/8/16/24/32/40/48/56/64/72 抽帧对齐），剪的时候如果画面切换早了/晚了，把字幕整体挪 1–2 秒即可。

## 加字幕的步骤（iMovie）

1. iMovie → 新建 App 预告片以外的「影片」，把录屏拖进时间线
2. 顶部「字幕」→ 选「下三分之一」或「标准字幕」样式
3. 按上表逐条拖入，改文字、拉时长对齐画面
4. 导出：文件 → 共享 → 文件 → 1080p

## 可选的加分动作（不用再录屏）

在视频**开头插 5 秒架构静帧**、**结尾插 5 秒结果汇总静帧**，各配一句字幕。
成本是两张图，收益是视频从「一次操作录屏」变成「有讲解的演示」。
